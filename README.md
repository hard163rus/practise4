## Задание 4-1: Динамическая память

```bash
cd ~/alga/practice4/task4_1
gcc -Wall -Wextra -o task task.c
./task
```

**Ожидаемый вывод:**
```
[malloc]  Выделено 400 байт под 100 элементов
[result]  Сумма чисел от 1 до 100 = 5050
[free]    Память освобождена
[calloc]  Выделено и обнулено 400 байт
[calloc]  arr2[0] = 0 (должен быть 0)
[realloc] Массив расширен до 200 элементов
[free]    Память освобождена
```

**Что происходит:**
- `malloc` — выделяет 400 байт (100 × 4 байта на int), память не инициализирована
- `calloc` — выделяет и обнуляет всю память
- `realloc` — расширяет существующий блок до нового размера
- `free` — освобождает память, предотвращает утечки

## Задание 4-2: mmap()

```bash
cd ~/alga/practice4/task4_2
gcc -Wall -Wextra -o task task.c
./task input.txt
```

**Ожидаемый вывод:**
```
[open]  Файл: input.txt, размер: 248 байт
[mmap]  Файл отображён в память по адресу 0x7f...
[result] Символов 'a' (строчных): 23
[result] Символов 'A' (заглавных): 8
[result] Итого 'a'+'A': 31
[munmap] Отображение снято
```

Можно проверить на любом другом файле:
```bash
./task /etc/hostname
./task /etc/os-release
```

**Что происходит:**
- `open` — открывает файл, получаем файловый дескриптор
- `fstat` — узнаём размер файла
- `mmap` — отображает файл в виртуальную память процесса (без явного `read`)
- После `mmap` файл доступен как обычный массив символов `mapped[i]`
- `munmap` — снимает отображение

## Задание 4-3: Демон

```bash
cd ~/alga/practice4/task4_3
gcc -Wall -Wextra -o task task.c
./task
```

**Вывод при запуске (и сразу возвращается приглашение):**
```
[parent] Демон запущен с PID 1234
[parent] Лог-файл: /tmp/daemon.log
[parent] Остановить: kill 1234
```

**Следим за лог-файлом в реальном времени:**
```bash
tail -f /tmp/daemon.log
```

**Ожидаемый вывод в daemon.log:**
```
=== Демон запущен ===
[2025-03-15 14:22:01] Демон работает
[2025-03-15 14:22:06] Демон работает
[2025-03-15 14:22:11] Демон работает
```

**Остановить демон:**
```bash
# Найти PID (если не записали):
pgrep -a task

# Остановить:
kill 1234
```

**Проверить что демон остановился:**
```bash
tail /tmp/daemon.log
# Последняя строка должна быть:
# === Демон остановлен ===
```

**Что происходит:**
- Первый `fork()` — отсоединяем процесс от терминала
- `setsid()` — создаём новую сессию, процесс больше не привязан к tty
- Второй `fork()` — процесс не может случайно захватить терминал
- `chdir("/")` — меняем директорию на корень (чтобы не блокировать размонтирование)
- `umask(0)` — сбрасываем маску прав
- Закрываем stdin/stdout/stderr и перенаправляем в /dev/null

## Задание 4-4: Анализ памяти

Установить нужные утилиты (если нет):
```bash
sudo apt install -y procps strace
```

### Запустить программу и получить PID:

```bash
cd ~/alga/practice4/task4_1
# Добавим sleep чтобы процесс не завершился мгновенно
./task & PID=$!
echo "PID: $PID"
```

### Анализ через pmap:
```bash
pmap $PID
```

### Карта памяти через /proc:
```bash
cat /proc/$PID/maps
cat /proc/$PID/status
```
